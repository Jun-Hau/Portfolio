Y3 S2 · TRC3500 Embedded · Signal Processing

Embedded Sensor Design & Signal Processing (3 Projects)

Designed, built, and characterised three complete sensing systems from the ground up — covering analogue circuit design, STM32 embedded interfacing, digital signal processing, and quantitative performance evaluation.

Project 1 — Soil Moisture Sensor

  • Constructed a resistive soil moisture sensor using stainless steel electrodes and a custom signal conditioning circuit, mapping sensor output to STM32 ADC range (0–4096).
  • Derived the linear transfer function: ADC = −38.79·M + 3723.6 over a 0–80 mL operating range.
  • Characterised sensor performance: repeatability error 5.42% FS, accuracy error 3.21% FS, with saturation behaviour documented beyond 80 mL.
  • Used LTspice to verify signal conditioning circuit before hardware implementation.

Project 2 — Piezoelectric Pin-Drop Impact Sensor

  • Built a piezoelectric sensor system to detect object-drop impact events using STM32 ADC and a 3D-printed drop stand for repeatability.
  • Developed a deadband filter and peak-detection algorithm to classify drop events from baseline noise.
  • Performed signal detection analysis (ROC curves, confusion matrix): achieved 91% accuracy, 98% recall, 91.6% F1 score across strong, weak, and no-drop conditions.
  • Excluded non-performance edge cases to define the effective sensing range.

Project 3 — Respiratory Rate Monitor

  • Developed a dual-modality breath-rate system using a TMP61 thermistor (airflow) and conductive rubber strain sensor (abdominal expansion), both interfaced to STM32.
  • Applied FFT-based digital signal processing on a 30-second sliding window to extract breathing frequency (BPM).
  • Implemented confidence-weighted sensor fusion to combine thermistor and strain sensor estimates, reducing MSE by up to 60% over single-sensor output.
  • Evaluated across 4 conditions (rest, talking, walking, jogging) — best performance at rest (MSE: 0.002 BPM²); completed Just-Noticeable Difference (JND) psychometric analysis.

Key Outcomes

  • Gained end-to-end experience in sensor design: from physical transducer to calibrated digital measurement.
  • Applied real-world signal processing and statistical evaluation (MSE, JND, repeatability, accuracy) to validate system performance.
